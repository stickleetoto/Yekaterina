# Yekaterina DLC model

Yekaterina Core v1 is the frozen base product. New domain capability is intended to ship as separately versioned DLC / extension packages.

Potential domains include:

- Advanced Mathematics
- Physics
- Mechanical Engineering
- Electrical / Electronic Engineering
- Robotics & Control
- Aerospace
- Chemistry
- Statistics & Data Science
- AI / ML Mathematics
- Quantitative Finance
- Biology / Scientific Computing

The user-facing goal is that installing DLC increases internal capability without expanding the core MCP surface beyond:

```text
yk.find
yk.spec
yk.compute
```

DLC may be offered under free or commercial licenses separate from the Yekaterina Core license.

Official DLC should ship with its own operation manifest, version, validation evidence, Golden vectors, boundary/property tests where appropriate, references/validity ranges, integrity data, and signature policy.
